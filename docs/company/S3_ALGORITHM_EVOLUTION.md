# S3 — Modification d'algorithme existant

## Objectif

Documenter une modification bornée d'un traitement existant sans provoquer de régression.

## Preuve attendue

- État initial.
- Demande de changement.
- Règle modifiée.
- Diff avant/après.
- Tests anciens et nouveaux.
- Résultat comparé.
- Validation référent.
