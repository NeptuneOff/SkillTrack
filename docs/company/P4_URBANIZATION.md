# P4 — Urbanisation SI anonymisée

## Positionnement

Le traitement repris s'insère entre des sources de données existantes et des fichiers de sortie utilisés pour analyse ou planification. Il ne remplace pas les systèmes maîtres ; il fiabilise une transformation.

## Points à prouver

- Sources amont.
- Données maîtres.
- Fréquence de traitement.
- Propriétaires.
- Stratégie de coexistence.
- Bascule et retour arrière.
