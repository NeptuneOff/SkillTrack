# P1 — Procédure entreprise anonymisée

Document à compléter avec validation du référent.

## Processus

Reprise d'un traitement Power Query vers Python dans un contexte industriel confidentiel.

## Acteurs

- Demandeur métier.
- Référent technique/tuteur.
- Développeur alternant.
- Valideur fonctionnel.

## Entrées et sorties

- Entrées : exports anonymisés, règles métier, traitement de référence.
- Sorties : fichier produit, rapport d'écarts, procédure de lancement.

## Contrôles

- Comparaison avec référence.
- Validation des écarts.
- Revue du référent.
