# Direction artistique — Nocturne Kinetic

Concept: application sportive technique, sombre, analytique, précise.

- Palette: fond noir bleuté, cyan, menthe, bleu électrique.
- Formes: cartes arrondies, surfaces translucides, séparateurs fins.
- Ton: professionnel, moderne, orienté performance.
- UI: dashboard prioritaire, navigation latérale, indicateurs chiffrés, barres de progression.
- Objectif jury: rendre le projet identifiable et moins générique qu’un CRUD scolaire.
